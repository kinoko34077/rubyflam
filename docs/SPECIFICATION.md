# Rubyflam（ルビ振らん）— ルビ記法ライブラリ初期要求・受入境界

## 名称・識別子
- ライブラリ正式名称: **Rubyflam**（日本語名: **ルビ振らん**）
- GitHubリポ: `kinoko34077/rubyflam`
- 将来の配布パッケージ識別子案: `rubyflam`（名称登録・ライセンス・リリースは未確定）
- 創設時のリポ名 `japanese-ruby-parser` はBootstrap履歴専用。現行の名前として再利用しない。

## 目的
「小説家になろう」および「青空文庫」のルビ構文を単体の共通ライブラリとして成立させ、将来的に既存各リポの重複ルビ処理の唯一の所有元とする。

## 要求
1. Narou mode: 公式仕様に基づき全角・半角縦線、明示・暗黙ルビ、半角／全角括弧による自動ルビ、括弧ルビ抑制、文字種・文字数上限、改行・連続記法・誤記・無効入力を判定する。公式挙動と異なる拡張は別modeに分離する。
2. Aozora mode: `aozora-wasm` を候補として既存実装を再利用し、青空文庫ルビを認識・構造化する。青空文庫全文組版機能全体の再実装は本件の目的ではない。
3. 共通出力: 解析結果の親文字、ルビ、入力記法、入力範囲、未解析原文を保持できる中間表現。レンダリング・語彙解析・表記変換から分離。
4. ラウンドトリップ: 元の記法を残す出力と正規化出力を区別し、意図せぬ基底範囲拡張・字句消失を防止。
5. 移植: `japanese-orthography/runtime/transform-shared.js` 由来の既存ルビ処理・試験を確認して移植。既存消費者との互換性回帰を通す。すべてを無条件でコピーせずルビ責務を抽出する。
6. 依存・権利: OSSの固定バージョン、実行依存のライセンス、著作権表示・NOTICE、公開物に含める元コードの権利を検証する。ライセンスは未決定。公開リポ作成≠npm公開。
7. 将来移行: 新ライブラリの受入後に、JO/TAR/kinotch-api等を棚卸しして実際の依存点から段階的に差し替える。既存の解析・歴史的仮名遣い・DOM/API機能を巻き込まず、同等性・失敗時復旧・source lockを検証する。

## 受入判定
- 公式仕様由来の肯定・否定・境界ケースが識別可能で、未確認事項を「完全互換」と称しない。
- Narou modeとAozora modeを混同せず、共通Ruby表現の同一性・原文保持・無効入力扱いを検証する。
- ブラウザ/Node等の想定実行環境で入口を検証し、必要ならWASMロード条件・bundleサイズも測定。
- ライセンス/NOTICEの配布条件を満たし、再現可能な依存固定とテストがある。
- 本ライブラリ自体の受入と、既存リポの段階的移行完了は別判定。
